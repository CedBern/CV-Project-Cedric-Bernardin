# Portfolio & CV - Cédric Bernardin

## Description (FR)
Ce dépôt héberge le site portfolio et le Curriculum Vitae interactif de Cédric Bernardin, actualisé en août 2026. Le site propose une expérience trilingue (français, espagnol, anglais) avec un commutateur de langue global en temps réel. Il présente son parcours professionnel d'enseignant de FLE, traducteur et concepteur pédagogique, ainsi qu'une grille détaillée de ses projets technologiques et applicatifs.

### Fonctionnalités & Projets
- **CV Trilingue Complet** : Présentation du parcours professionnel (Coach *French Immersion*, Alliance Française de Mérida, Université Anáhuac, UNAM ENES, etc.) et formation académique.
- **Grille de Projets Interactifs** : Fiches détaillées trilingues avec visuels haute fidélité pour :
  1. **MayaVoiceTranslator** : Outil de traduction vocale et écrite trilingue (maya yucatèque, espagnol, français) pour la préservation linguistique.
  2. **IASA - Gestion Geoespacial** : Système géospatial entreprise de gestion des déchets solides (PHP 8.4, CodeIgniter 4, PostgreSQL/PostGIS, PWA chauffeurs, capteurs IoT, OSRM).
  3. **Horizons** : Portail webzine interactif (React + Vite) hébergeant les productions étudiants de l'Alliance Française de Mérida.
  4. **Pronos Alliance** : Application ludique et pédagogique FLE de pronostics Coupe du Monde 2026 (Next.js 16, Supabase PostgreSQL, Quiz FLE, Clans & Chat).
  5. **PokerMTT Pro (Fish & Chips)** : Assistant d'aide à la décision et plateforme d'entraînement MTT No-Limit Hold'em (moteur SRS Leitner, calcul d'équité & ICM).
  6. **Criterio OSINT** : Revue numérique trilingue d'investigation géoarchéologique, de fact-checking et de debunking OSINT avec modules didactiques interactifs.
- **Design Moderne & Réactif** : Interface conçue avec TailwindCSS, typographies dynamiques (Montserrat + Outfit) et effets glassmorphismes.

## Description (EN)
This repository hosts the interactive portfolio and Curriculum Vitae website of Cédric Bernardin, updated in August 2026. The website provides a trilingual user experience (French, Spanish, English) with a global, real-time language switcher. It showcases his professional career as a French teacher, translator, and instructional designer, alongside a dynamic project grid presenting his technical applications and platforms.

### Key Features & Projects
- **Trilingual Resume**: Features his positions (Coach with *French Immersion*, Alliance Française of Mérida, Anáhuac University, UNAM ENES, etc.) and education.
- **Interactive Projects Dashboard**: Detailed trilingual sheets and high-fidelity mockups for:
  1. **MayaVoiceTranslator**: A trilingual Mayan-Spanish-French speech and text translator built for cultural preservation.
  2. **IASA - Geospatial Waste Management**: Enterprise geospatial solid waste management system (PHP 8.4, CodeIgniter 4, PostgreSQL/PostGIS, Driver PWA, IoT telematics, OSRM).
  3. **Horizons**: An interactive webzine portal (React + Vite) hosting multimedia student projects for the Alliance Française of Mérida.
  4. **Pronos Alliance**: Gamified FLE World Cup 2026 prediction platform for Alliance Française (Next.js 16, Supabase PostgreSQL, FLE Quizzes, Clans & Chat).
  5. **PokerMTT Pro (Fish & Chips)**: Decision support and spaced-repetition training suite for No-Limit Hold'em tournaments (SRS Leitner, equity & ICM).
  6. **Criterio OSINT**: Trilingual digital webzine for geoarchaeological investigation, debunking, and OSINT fact-checking with interactive didactic modules.
- **Modern Responsive UI**: Styled using TailwindCSS and custom CSS variables, optimized for all screen dimensions.
